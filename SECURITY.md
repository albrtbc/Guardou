# Security Policy

This repository is a fork of [GuardouApp/Guardou](https://github.com/GuardouApp/Guardou). Security fixes for this fork are made here.

## Supported versions

Only the latest release of this fork is supported. Upgrade to it before you report a problem, if you can.

## Reporting a Vulnerability

Please report vulnerabilities privately, through this repository's [security advisories](https://github.com/albrtbc/Guardou/security/advisories/new). Don't open a public issue for them.

Say which version you run, what you did, and what happened. If you can, say what you expected instead.
